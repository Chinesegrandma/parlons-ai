# Pause、英文解释与 Camille（2026-10-25）

## 修复与行为

1. 录音中的 Pause 不再丢弃当前录音。它结束当前段，自动转写、发送和回复，
   等朗读结束后暂停，不会重新录音。转写/等待回复时点击 Pause 也会完成当前段。
   处理中同一按钮变成 Cancel，可明确取消；切换模式、离开或隐藏页面仍丢弃未提交片段。
   等待麦克风权限、转写、回复与准备暂停现在显示不同状态。
2. English 设置明确要求解释和复习提示使用英语；法语回复与 corrected_text 保持法语。
   对明显的法语/中文解释做语言检查，仅在识别到违约时额外请求一次解释翻译，
   不修改回复或纠正后的法语句子。二次仍失败则报错并保留草稿，不存错误语言反馈。
   检查是启发式的，并非完备语言识别器，未对真实模型新输出做质量验证。
   这一步最多增加一次 OpenAI 请求；正常英语或连续模式隐藏的反馈不增加请求。
   之前已保存的反馈不会自动付费翻译。
3. 固定女生 AI 助理 Camille，头像是本地内联 SVG，不请求外部图片。
   每段新对话第一条开场包含一句介绍，保存在原有的同一条 opening 中，
   刷新不会多插一条；已有会话不覆盖历史开场。系统提示避免每轮重复介绍。

## 验证

- 154 项后端、68 项前端测试通过；Ruff、格式、ESLint、TypeScript、生产构建通过。
- 回归覆盖手动 Pause 提交、回应后不再录音、明确 Cancel 的迟到响应防护、
  英语反馈语言修复、一次重试上限、法语对话保持原样、失败不写入历史、
  人设开场持久化/幂等/模型上下文和女生头像渲染。
- 实际 Chromium HTTPS + MediaRecorder 浏览器测试使用人工正弦音夹具：
  未等自动停顿便点 Pause，得到一次转写、一次对话回复，朗读后保持暂停；
  English 请求和界面、Camille 介绍与头像、390px 无溢出均通过。
- 所有开发和验证均为 MOCK_AI=true，没有真实 API、付费调用或部署。
  合成音频只验证交互，不验证真实识别或发音/纠错质量。
