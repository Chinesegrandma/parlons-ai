# 场景入口、连续对话和双语界面

本轮回应六项使用反馈，开发、自动化与浏览器验证全部使用 `MOCK_AI=true`。
未部署站点，未调用 OpenAI 或 ElevenLabs 真实服务。

## 入口与聊天

首页分成办事、日常、社交、学业与工作、面试五个大板块，并提供直接开始聊天。
办事中的银行分办卡与转账，医院分预约挂号与描述症状；学校分选课与和老师沟通。
另有租房、邮局、客服电话、用餐、咖啡馆、购物、交通、问路、自我介绍、朋友闲聊、
邀请、拒绝、工作汇报。点击具体事项即进入对话，面试大板块直接进入。
分类浏览不创建会话，也不请求朗读。开始对话才保存会话并尝试播放开场。
既有话题 ID 和数据库保持兼容，前后端目录一致性有测试覆盖。

聊天页去掉灵感和工具面板，主要保留模式切换、录音/输入、播放和结束总结。
AI 系统提示改为主动承接上一句话、每次提出一个具体问题；短回答时可给两个选择。
提示词行为通过模拟断言验证，真实主动提问质量尚未重新评估。

## 两种模式

- 逐句练习：录音、检查编辑转写、发送、即时文字纠错，支持打字。
- 连续对话：点击一次开启；本地 Web Audio 检测讲话后约 1.4 秒停顿，自动完成
  转写、发送、朗读，再恢复录音。麦克风在播放期间关闭。
  此模式不显示/保存逐轮纠错，结束时基于全部对话生成总结。

连续模式使用现有 ElevenLabs STT + OpenAI + ElevenLabs TTS，存在逐轮等待，
不是持续流式、可打断的实时通话。无需购买新的 API。每轮会自动调用三个服务操作，
继续共用每分钟/每天请求限额；总结也占用一次额度。设置中的自动朗读开关针对逐句模式，
连续语音模式需要朗读来推进轮次。

Pause 会先提交当前录音、完成回复，然后停止下一轮录音。处理中可用 Cancel 取消。
切换模式、离开聊天、隐藏页面、录音或服务失败都会停止本地录音/下一轮循环。
已发出的语言模型请求可能仍完成并收费，但迟到结果不会重启录音或朗读。
尚未发出的不完整录音不会因 Cancel、模式切换或离开页面而上传。用户原始转写依然单独保存，不持久化原始录音。
超过 12 秒未检测到讲话会暂停；单段仍受 60 秒、8MB 上限保护。
噪声阈值固定，嘈杂环境可能误分段；尚未在真实 iPhone/Android 上验证。
不支持 Web Audio/MediaRecorder 的浏览器可使用逐句或文字模式。

## 开场与语言

点击具体场景时尝试解锁音频，新会话开场自动朗读一次，不因渲染重复播放。
关闭自动朗读会遵守选择。浏览器拒绝自动播放时保留已生成音频并显示点击播放入口，
不因点击重试再次调用 TTS。浏览器权限策略无法被应用强行绕过。

设置提供“语言”：中文、English，同时控制界面、新的纠错解释和结束总结。
法语对话本身保持法语；旧的模型反馈不会因更改设置而重新付费翻译。
语言保存在本地，并用非敏感 Cookie 支持登录页语言选择。
“更多偏好”统一命名为“练习偏好”。

## 总结

`POST /sessions/{id}/review` 读取全部已存文字记录，输出总结、带原句证据的优点、
带原句/改写/解释的纠错。不会把语音转写当作发音评分；只允许引用用户消息中的文字，
拒绝无依据的引用。超过 100,000 字符的会话显式返回 413，避免冒充覆盖全部记录。
总结受模型能力和输出预算约束，不能保证找出所有错误；不自动保存在数据库。

## 验证

执行 `PARLONS_PYTHON=... bash scripts/check.sh`：后端 Ruff/pytest、离线评估、
前端格式、ESLint、TypeScript、Vitest、Next.js 生产构建。
新增覆盖分级入口单次进入、首页不产生付费调用、英文界面与请求语言、开场朗读与禁用、
连续轮次、播放结束等待、暂停后的迟到响应、模式切换时不上传半段录音、
有证据的正负反馈、完整历史、无依据引用拒绝、总结限流和登录页英语。

实际 Chromium HTTPS 浏览器连接生产构建与模拟后端，使用人工合成的正弦音加静音 WAV
驱动真实 MediaRecorder/Web Audio，验证登录、分级选择、开场、停顿、自动转写/发送、
播放后恢复录音、取消时无额外上传、结束总结和中英切换。无外部请求、脚本错误或 CSP 违规，
390px 视口无横向溢出。该合成样例只验证交互与分段流程，不能证明真实识别或教学质量。
