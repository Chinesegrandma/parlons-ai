# 引导练习版本

本轮围绕“更多练习场景和引导”改进已有网页，不改变提供商或真实调用开关。

## 变化

- 在原有日常、咖啡馆、旅行、面试基础上新增餐厅、购物、看诊预约、朋友邀约。
- 场景库支持中法文搜索，显示建议难度、场景介绍及练习入口。
- 每个场景提供三个小任务、对应表达提示和词汇。点击“填入草稿”后可以编辑，
  不自动发送；已有草稿时禁用填入，避免覆盖。用户主动勾选任务可撤销，
  当前记录随本次组件会话保留，刷新后清除，并非 AI 评分。
- 后端提供各场景专属开场和角色上下文。看诊场景定位为向前台预约的语言练习。
- 手机顶部横向场景导航替代窄侧栏，聊天获得完整宽度；卡片、输入和按钮适配窄屏。
- 新增录音计时、独立转写状态和多行输入，保留 Enter 发送与输入法组合保护。
- `/demo` 的新场景同样使用明确标记的脚本回复，不访问提供商。

## 使用

从首页点击“探索 8 个生活场景”，选一个场景，查看三个任务。
不会说时点击任务旁的“提示”，将表达填入空草稿，修改后发送。
完成某项后可自行打勾。切换场景创建新会话，历史仍保存在 SQLite，
目前页面只自动恢复最近会话，尚未提供完整历史会话列表。

## 验证

`MOCK_AI=true` 下运行 `scripts/check.sh`：Ruff、pytest、离线评估、
Prettier、ESLint、TypeScript、Vitest 和 Next.js 生产构建。
新增测试覆盖八个场景的持久化开场与 LLM 上下文，以及场景搜索、任务勾选、
提示不自动发送、已有草稿保护、多行键盘行为。

不宣称模拟测试验证了法语语音识别或真实教学效果。建议难度标签由人工编写；
本轮没有引入正式能力分级、自动任务评判、持续实时通话或语音发音评分。

## Mac 更新

下载 `work` 分支的新 ZIP 到一个新文件夹，保留旧项目文件夹作为备份。
在新文件夹打开终端，执行 `python3 scripts/run_local.py --tunnel` 先体验模拟版，
确认布局后再用 `--tunnel --real`。首次运行会重新准备依赖。
旧对话仍留在旧目录的 `backend/parlons.sqlite3`；不要删除旧目录。
如需迁移历史，先关闭两边应用，再将该数据库复制到新目录的 `backend/`。
API 密钥不会包含在下载文件内，真实模式仍会提示隐藏输入。
